# Phase 10.3: Sound Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Sound effects and ambience for everything the game does, made with ElevenLabs on Comfy Cloud and played through a small Web Audio engine.

**Architecture:**
- `src/audio/sfx/` holds the pure parts: the catalogue of sounds, variant picking, falloff, panning, voice caps, the ambience mix and the ground underfoot. It also holds the `Sfx` engine, a thin Web Audio layer over them.
- A render-side `SoundDirector` turns sea, land, treasure, duel and menu events into `Sfx` calls, beside `Effects`.
- The sounds are generated outside the game with the Comfy Cloud MCP, then trimmed, levelled and looped by an ffmpeg script into `src/assets/sfx/`.
- A dev-only board at `/?sounds` plays every one.

**Tech Stack:** TypeScript (strict), Vite (`import.meta.glob`), Web Audio API, Vitest, ffmpeg via `tsx` scripts.

**Spec:** `docs/phase-10-deposits-guns-sound.md`, section "10.3 Sound", and its Tests section. Read `docs/ARCHITECTURE.md` §14 and §15 for the sim/render split.

## Global Constraints

- One audio context, started by the first key press or click (as the music is).
- An "Effects volume" setting beside "Music volume", with Off. Same choices as music: `VOLUME_CHOICES` (0, 0.25, 0.5, 0.75, 1).
- Each sound has variants: one is picked at random and played with a slight pitch shift.
- Sounds get quieter with distance from the camera's focus, and pan with where they are on screen.
- About 24 voices at once (`MAX_VOICES = 24`), with per-sound caps (footsteps 2, cannon 8); the oldest is cut.
- Ambience loops crossfade by where the captain is and what's happening; the wind in the rigging follows the wind's strength.
- Footsteps follow the walk cycle and the ground underfoot.
- The sound files are small mono MP3s in `src/assets/sfx/`, named `<id>-<take>.mp3` (e.g. `hull-hit-2.mp3`). Loops have their ends crossfaded so they repeat seamlessly.
- Every prompt goes in `docs/sfx.md`, like `docs/music.md`.
- A missing sound file is never an error: the game must run and pass its tests with `src/assets/sfx/` empty, before anything is generated.
- `sim` modules (`land/`, `combat/`, `duel/`, …) must not import from `audio/`, `render/` or `ui/` (ARCHITECTURE §15).
- Code style: match the surrounding code. Doc comments in plain British English, `readonly`, small pure functions, tests in `*.test.ts` next to the code.
- Stage files by path. Never stage `.opencode/`, `.env` or raw downloads.

## Review Focus

1. **No sound files yet, or a file that fails to load or decode.** The game should run silently for that sound, without an exception or console spam. *Test:* the Task 2 test `plays nothing, and throws nothing, for a sound with no files or a failed decode`.
2. **Effects volume Off.** Nothing should play and no buffers should download, as with the music's Off. *Test:* the Task 2 test `volume 0 plays nothing and loads nothing`.
3. **The tab hidden, a menu open, asleep or faded out.** Ambience should fall silent, not keep looping. *Test:* the Task 3 test `everything is silent when where is null`, plus Game passing `where: null` in those states, as the music does.
4. **A burst of events in one frame** (a broadside of 8 cannon, or a settler gang chopping). The caps should hold, the oldest voice should be cut, and the number of live voices should never exceed 24. *Test:* the Task 1 test `never holds more than the cap per key, nor MAX_VOICES in all`.
5. **Sounds from far away** (a settler chopping on an island across the sea). They should be inaudible beyond their reach, and dropped rather than played at zero gain, so they use up no voices. *Test:* the Task 2 test `drops a sound out of reach without taking a voice`.

### Task 3: The ambience mix

**Files:**
- Create: `src/audio/sfx/ambience.ts`
- Test: `src/audio/sfx/ambience.test.ts`

**Interfaces:**
- Consumes: `LoopId`, `LOOP_IDS` (Task 1). `VoxelReader` and `SEA_LEVEL` from the voxel core and `config.ts`.
- Produces:
  ```ts
  export interface Surroundings {
    where: 'sea' | 'land' | null;
    speed: number;   // the ship's speed over her top speed, 0..1
    wind: number;    // Wind.strength where the captain is (0..~1.8)
    shore: number;   // on foot: distance to open water (Infinity if none within reach)
    port: number;    // distance to the nearest port's centre
    fire: number;    // distance to the nearest lit campfire or bandit fire
    night: boolean;
  }
  export function ambience(s: Surroundings): Record<LoopId, number>;
  export function shoreDistance(world: VoxelReader, x: number, z: number, reach?: number): number; // reach default 30
  ```

- [ ] **Step 1: Write the failing tests**
  - `everything is silent when where is null`: every level is 0.
  - `at sea, waves and timbers rise with speed and the rigging follows the wind`:
    - waves = `0.5 + 0.4 × speed`;
    - timbers = `0.25 + 0.45 × speed`;
    - rigging = `0.7 × min(1, wind)`;
    - surf = 0.
  - `on foot, the surf fades out over 30 blocks from the water and the ship's sounds are gone`: shore 0 → surf 0.8; shore 15 → 0.2; shore ≥ 30 → 0. Use `0.8 × (1 - shore/30)²`. Waves, timbers and rigging are 0.
  - `gulls by day near a port, at sea or ashore; the harbour bustle only ashore in port`:
    - gulls = `0.6 × (1 - port/150)` for port < 150 by day, and 0 at night;
    - harbour = `0.7 × (1 - port/60)` on land for port < 60, halved at night, and 0 at sea.
  - `the campfire crackles within 12 blocks`: fire 0 → 0.9; fire 6 → `0.9 × 0.25`; fire 12 → 0. Use `0.9 × (1 - fire/12)²`. It's 0 at sea.
  - `shoreDistance finds the nearest open water`: build a small `VoxelWorld` with ground to x = 9 and nothing beyond, so a column with no solid cell at `SEA_LEVEL - 1` is water. From x = 0 the answer is about 10 (±3, it samples on a coarse ring). With ground all round, it's `Infinity`.
